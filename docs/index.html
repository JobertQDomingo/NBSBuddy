NBSBuddy

File your work-from-home OB + Change Shift in NBS in a couple of clicks, and see which days need action before payroll cutoff.

Download for Windows

Latest version · Windows 10 / 11 · needs ZeroTier and your NBS account

File CS/OB

Two clicks a day

Pick your shift; NBSBuddy fills in the OB times and files OB and CS together, skipping whatever's already in NBS.

Done Needs action

Cutoff at a glance

Every workday of the payroll period gets one sticker, so missing, disapproved or late days jump out before cutoff.

For Approval

Undo a mistake

Filed the wrong shift? Delete a filing while it's still For Approval, then file the day again.

Install

  1. Click Download for Windows and run NBSBuddy-setup.exe. No admin rights needed.
  2. Connect ZeroTier. NBS is only reachable on the company network.
  3. Open NBSBuddy and sign in with your NBS username and password. Tick Remember me to skip sign-in next time.
"Windows protected your PC"? The installer isn't code-signed yet, so Windows SmartScreen asks first. Click More info, then Run anyway.
